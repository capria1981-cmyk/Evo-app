Chat — EVO

This page has two sections:

  1. Local EVO chat — a lightweight client-side chat UI that can optionally call OpenAI if you paste your API key (key stays in your browser).
  2. External agents — quick-launch buttons that open the official web apps for each AI tool.

1) EVO (Local Chat)

Note: You can try EVO locally by pasting an OpenAI API key (sk-...). If you don't provide one, the UI still works as a local notepad-style chat.

If you supply an OpenAI key, EVO will send your messages to OpenAI's Chat Completions API from your browser (your key is never sent to any server by this page).
